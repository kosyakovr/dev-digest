# specs

This folder holds two kinds of specs:

- **`NN-name.flow.json`** — executable browser flows run by `../run.ts` (it only
  picks up `*.flow.json`). Format and rules: [../README.md](../README.md).
- **`*.md`** — written feature specs for new flows, started from
  [_template.md](_template.md). Name them after the flow they describe
  (e.g. `08-cost-badge.md` → `08-cost-badge.flow.json`).
