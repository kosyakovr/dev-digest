# specs

Feature specs written **before** implementation. One file per feature:
`<lesson>-<feature>.md` (e.g. `L01-cost-badge.md`), started from [_template.md](_template.md).

- Update `Status` as work progresses; mark `done` when merged.
- A feature spanning several packages keeps ONE spec — link to it from the other
  packages' `specs/` instead of duplicating it.
